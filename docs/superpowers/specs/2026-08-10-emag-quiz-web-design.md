# 전기기사 전자기학 3회 기출 웹 문서 — 설계서

날짜: 2026-08-10

## 목적

유튜브 영상(https://www.youtube.com/watch?v=BlGWW66ZRaY)에 수록된 전기기사 전자기학 3회 기출문제와 해설을, 수험생이 링크 하나로 접근해 풀고 복습할 수 있는 웹 문서로 만들어 GitHub Pages에 배포한다.

## 요구사항

- 구성: 문제 중심형 — 문제 → 해설 → 관련 이론 요약 순서
- 이론 요약 깊이: 미니 이론 정리 (공식 + 개념 설명 + 자주 나오는 함정/유형 포인트)
- 형태: 단일 페이지 정적 HTML (`index.html`) + 정답 판정 인터랙션 (1안+3안 절충)
- 각 문제 해설에 해당 유튜브 타임스탬프 링크 포함
- 배포: GitHub 공개 저장소 + GitHub Pages

## 콘텐츠 제작 파이프라인

1. watch 스킬로 영상 분석: 프레임에서 문제 지문·보기·수식 추출, 자막에서 해설 추출, 문제별 타임스탬프 기록
2. PDF(`kim0sun68@gmail.com___김영선___전기기사필기.pdf`)의 전자기학 파트에서 각 문제 관련 이론을 찾아 미니 이론 정리로 요약
3. 콘텐츠를 `index.html`에 반영

## 페이지 구조 (index.html)

- 상단: 제목("2026 전기기사 전자기학 3회 기출"), 원본 영상 링크, 사용 안내 한 줄, 점수 현황("n/전체 정답")
- 문제 카드(반복):
  - 문제 번호, 지문, 보기 ①~④ (클릭 가능한 버튼)
  - 보기 클릭 시: 정답이면 초록 ✓, 오답이면 선택 보기 빨강 ✗ + 정답 보기 초록 표시 → 해설 자동 펼침
  - [해설 보기] 버튼: 클릭 없이 바로 해설을 볼 수 있는 대체 경로
  - 해설 내용: 정답, 풀이 과정, 미니 이론 정리, "▶ 영상 해설 바로가기" 링크(`youtu.be/BlGWW66ZRaY?t=초`)
- 점수는 페이지 내 상태로만 유지 (저장 없음, 새로고침 시 초기화)

## 기술

- 순수 정적 HTML/CSS/JS 단일 파일, 외부 의존성은 KaTeX(CDN)만 사용
- 수식: KaTeX 렌더링
- 모바일 반응형 (수험생 다수가 모바일로 접근)

## 배포

- GitHub 공개 저장소 생성 → `index.html` 푸시 → GitHub Pages 활성화 → 공유 URL 확보
- 저장소 생성 및 공개 배포 직전에 사용자에게 저장소 이름과 함께 확인받고 진행

## 검증

- 브라우저에서 실제 열어 확인: KaTeX 수식 렌더링, 보기 클릭 정답 판정, 해설 펼침, 타임스탬프 링크 이동, 모바일 뷰
- 문제·정답·해설 내용이 영상과 일치하는지 대조
